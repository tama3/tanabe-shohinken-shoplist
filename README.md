# 田辺市商品券 取扱店舗検索

田辺市商品券事業の取扱店舗（752店舗）を地区・業種・キーワードで検索できる、モバイル対応の静的サイトです。

## 構成

- `index.html` — アプリ本体（HTML + CSS + JS 一体）
- `data.js` — CSV から生成された店舗データ（`window.STORES`）
- `scripts/convert.mjs` — CSV → `data.js` 変換スクリプト
- `田辺市商品券事業_*.csv` — 原本データ

外部ライブラリ・ビルドツールは未使用。ブラウザで `index.html` を直接開くだけで動きます。

## ローカル確認

`index.html` をブラウザで開くだけ（`file://` でも動作）。

## データ更新手順

1. プロジェクトルートの CSV ファイルを最新版で置き換える（ファイル名は何でも可、拡張子 `.csv` のみ判定）
2. 変換スクリプトを実行:
   ```sh
   node scripts/convert.mjs
   ```
3. 生成された `data.js` を commit して push

## 検索仕様

- **キーワード検索**: 店舗名・地区・地名・業種・取扱品目の全列を横断
- **正規化**: 大文字小文字／全角半角／ひらがなカタカナ／小書き仮名／長音記号 を吸収
  - 例: `ファミマ` `ふぁみま` `ﾌｧﾐﾏ` はいずれも `ファミリーマート` 系にマッチ
- **AND 検索**: スペース区切りで複数キーワード（全てを含む店舗が対象）
- **絞り込み**: 地区（6種）・業種（5種）を複数選択可
- **URL 同期**: 検索条件は `?q=...&area=...&cat=...` 形式で保持・共有可能

## デプロイ（GitHub Pages の例）

1. GitHub にリポジトリを作成して push
2. リポジトリの **Settings → Pages**
3. **Source**: `Deploy from a branch` → `main` / `/ (root)` を選択
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

Cloudflare Pages / Netlify / Vercel でも同様に静的サイトとしてデプロイ可。
